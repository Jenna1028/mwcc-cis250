Question 3: 

fork() can return three different values. A negative valye means the process could not be created. A value of 0 
means the code is running in the child process. A positive value means the code is running in the parent process
and the value represents the child process's ID. 

Question 4: 

When execvp() succeds, it replaces the child process's current program with the new command that's being executed.
The child process runs the new program instead of continuing it with the original code, and then terminates the 
child process once the command finishes.

Question 6:

The test runner uses the childs exit status to determine whether a test past or failed. If the child process terminates
normally with an exit status of 0, the test passes and if it returns a nonzero exit status or terminates abnormally,
then it fails.

Question 8:  

If the parent launched all tests without waiting, then multiple tests could run at the same time causing their outputs to
get mixed together and making it difficylt to tell which results belong to which. They can also interfere with each other 
if they are using the same files or resources. Waiting amkes sure that each tests finishes before the next one begins,
